# Titanic Survival Prediction

This project focuses on data cleaning and feature engineering using the Kaggle Titanic dataset.

## Technologies Used

Python

Pandas

NumPy

Seaborn

Scikit-learn

Jupyter Notebook

## Work Done

Loaded and explored the dataset

Handled missing values

Filled missing Age values using group-wise median based on Sex and Pclass

Filled missing Embarked values using mode

Created new features such as FamilySize, Fare Groups and Title

Encoded categorical variables using Label Encoding

Visualized feature correlations using a heatmap

Prepared the dataset for machine learning

## Dataset

Titanic - Machine Learning from Disaster (Kaggle)
